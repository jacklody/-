# 日历助手 - 智能待办管理系统

一个现代化的智能日历与待办管理应用，基于设计稿实现，保持与原设计一致的视觉效果。

## 功能特性

### 核心页面

1. **工作台·月视图** (`month-view`)
   - 月历展示，显示每日待办概况
   - 统计卡片（今日待办、已完成、逾期、完成率）
   - 待办列表，支持完成状态切换
   - 今日日程快速查看

2. **工作台·周视图** (`week-view`)
   - 周视图网格布局
   - **拖拽功能**：可跨日期拖拽待办卡片
   - 拖拽时自动识别"提前完成"或"延期"状态
   - 统计概览和周总结

3. **提醒中心** (`reminder`)
   - 今日时间线视图
   - 逾期提醒告警
   - 未来7天预览
   - 提醒设置（时间、方式、免打扰）

4. **智能导入** (`smart-import`)
   - 多源待办聚合（飞书、邮件、微信）
   - 连接状态管理
   - 最近导入历史

5. **集成设置** (`integration`)
   - 外部平台集成管理
   - 同步设置
   - 连接状态监控

### 交互特性

- ✅ **响应式设计**：适配桌面端和移动端
- ✅ **主题切换**：支持亮色/暗色主题
- ✅ **拖拽交互**：周视图支持拖拽待办卡片
- ✅ **动态路由**：基于hash的单页应用路由
- ✅ **状态管理**：全局状态管理
- ✅ **微动画**：过渡动画和悬停效果

## 技术栈

- **纯前端实现**：HTML + CSS + JavaScript
- **图标库**：Lucide Icons
- **设计系统**：CSS变量驱动的主题系统
- **路由**：基于hash的SPA路由

## 快速开始

### 方式一：使用启动脚本

```bash
# 添加执行权限
chmod +x start.sh

# 启动服务
./start.sh
```

然后在浏览器中打开 http://localhost:8080

### 方式二：直接打开文件

直接在浏览器中打开 `index.html` 文件即可

### 方式三：使用其他HTTP服务器

```bash
# Node.js
npx serve .

# PHP
php -S localhost:8080

# Python
python -m http.server 8080
```

  - 次要：#ffa502 (橙)

- 桌面端：> 1200px
- 平板端：768px - 1200px

## 主题切换

点击侧边栏底部的设置按钮即可切换亮色/暗色主题，主题偏好会保存在本地存储中。

## 拖拽功能使用

在周视图页面，可以拖拽待办卡片到不同日期：

1. 点击并按住待办卡片
2. 拖动到目标日期
3. 松开鼠标完成移动
4. 系统会自动识别：
   - 拖到更早日期 = 提前完成
   - 拖到更晚日期 = 延期
